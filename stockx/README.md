# StockX — Modern Stock Market Learning & Trading Web Application

> **Tagline:** *"Track. Analyze. Learn. Invest."*

StockX is a modern fintech web application designed for learning, market analysis, and paper trading. Built with a responsive dark-slate fintech design aesthetic (`#0B0F14`), smooth micro-interactions, interactive Chart.js financial charts, and virtual portfolio management.

---

## ⚠️ Important Simulation Notice

**StockX is an educational and demo stock market simulation application.**
All stock quotes, market indices, portfolio valuations, and transaction logs are **simulated** for demonstration, paper trading, and educational purposes. No real financial capital is at risk.

---

## 🛠 Tech Stack

- **Frontend:**
  - Modern HTML5 semantic layout
  - Responsive CSS3 design system with CSS custom properties (Variables), Glassmorphism, and Flexbox/Grid
  - Vanilla JavaScript (ES6+) for ultra-fast, zero-bloat state management and event handling
  - **Chart.js:** Interactive stock performance charts with multi-timeframe toggles (1D, 1W, 1M, 6M, 1Y, 5Y) and portfolio asset allocation donut visualizer
- **Backend:**
  - Python 3.11+
  - **FastAPI:** High-performance async REST API framework with Swagger / OpenAPI documentation
  - **SQLAlchemy:** ORM with SQLite database integration
  - **Pydantic:** Type-safe schema validation
  - **Passlib & JWT:** Secure password hashing and token-based authentication
- **Mobile / Android Container:**
  - Jetpack Compose with edge-to-edge support and embedded high-performance WebView running the application natively.

## 🚀 Quickstart & Installation

### 1. Backend Setup (FastAPI & SQLite)

1. Open a terminal and navigate to the project root:
   ```bash
   cd stockx
   ```
2. Create and activate a Python virtual environment:
   ```bash
   python3 -m venv venv
   source venv/bin/activate    # On Windows use: venv\Scripts\activate
   ```
3. Install required Python packages:
   ```bash
   pip install -r requirements.txt
   ```
4. Initialize and seed the SQLite database with demo accounts, sample stocks, and initial holdings:
   ```bash
   python3 -m backend.seed_data
   ```
5. Start the FastAPI development server:
   ```bash
   uvicorn backend.main:app --host 0.0.0.0 --port 8000 --reload
   ```
   - Interactive API Docs (Swagger UI): **http://localhost:8000/docs**
   - Alternative Docs (ReDoc): **http://localhost:8000/redoc**

---

### 2. Frontend Setup

The frontend is completely self-contained:
- **Direct Browser Access:** Simply open `stockx/frontend/index.html` in any web browser.
- **Local Static Server:**
  ```bash
  cd stockx/frontend
  python3 -m http.server 3000
  ```
  Then visit `http://localhost:3000`.

## 🔌 Connecting Live Market Data APIs in the Future

To upgrade from simulated prices to live market quotes:

1. **Recommended API Providers:**
   - **Indian Markets (NSE/BSE):** Zerodha Kite Connect, Angel One SmartAPI, Upstox API, or Yahoo Finance (`yfinance`).
   - **Global Markets:** Alpha Vantage, Polygon.io, or Finnhub.
2. **Integration Steps:**
   - In `backend/routes/stocks_routes.py`, replace the price lookup with a cached async fetch call to your chosen provider.
   - In `stockx/frontend/js/app.js`, set `this.apiBase` to your production API endpoint via the Settings page.
